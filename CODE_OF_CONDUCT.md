# Code of conduct

This project follows the Contributor Covenant, version 2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, keep feedback about the work and not the person, and assume good faith. Harassment, personal attacks and publishing other people's private information are not acceptable here.

## Enforcement

The maintainer may edit, hide or remove comments, issues and pull requests that break this code, and may block repeat offenders. To report a conduct problem, use the private "Report a vulnerability" button on the Security tab (it is the only private channel this repository has) or write through https://puodziukas.dev.

Conduct reports are handled by the single maintainer on a best-effort basis, with the same targets as `SECURITY.md`.
